# 播放进度问题诊断

## 手机端采集

1. 更新页面后，确认历史页已经加载了新的版本。
2. 打开目标录音，按正常方式播放并复现进度条跳动。
3. 点击录音旁的“反馈播放问题”。可以补充跳动发生的时机，但不是必填。
4. 页面会收集当前播放尝试的最近一段事件并发送；断网时会在本机暂存，网络恢复后自动补传。

一次反馈只对应当前选中的录音和当前播放尝试，不会读取或上传其他会话、音频内容、逐字稿、鉴权信息或完整页面地址。

## 分析单个诊断包

只对明确指定的一个 `snapshot.json` 执行分析：

```powershell
python tools/analyze_playback_diagnostic.py --input <snapshot.json 的完整路径>
```

分析结果会分开列出现场证据、候选解释和缺失证据。命中候选并不等于已经确认根因；需要结合 `buildId`、播放尝试编号和真实设备复现继续判断。

## 验收边界

自动测试和本地构建只能证明采集链路可用，不能证明手机上的进度条问题已经修复。收到真实故障包后，先按包内时间线定位，再决定是否修改播放方案。

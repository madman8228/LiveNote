# LiveNote 项目宪法

## 交互原则

### 禁止浏览器原生提示框

用户可见的 PWA、手机页面和 PC 控制台禁止使用浏览器原生的：

- `window.alert`
- `window.confirm`
- `window.prompt`

原生提示框会显示 `127.0.0.1:端口` 或真实域名，打断页面上下文，在手机端也不便于确认和恢复。

所有确认、危险操作和错误恢复必须使用页面内的控件完成，例如：

- 同一行显示“确认 / 取消”；
- 页面内显示状态和错误信息；
- 使用按钮禁用、加载状态和明确的结果反馈。

这条规则适用于新增功能、重构和修复，不得为了省代码重新引入原生提示框。
